# المترجم العربي الفرنسي — Offline Web/PWA

موقع/PWA لترجمة العربية ↔ الفرنسية محليًا باستخدام نموذجي:

- Helsinki-NLP/opus-mt-ar-fr
- Helsinki-NLP/opus-mt-fr-ar

## الفكرة

ملفات النموذج الأصلية لدى Helsinki-NLP هي نماذج Marian/PyTorch وليست صيغة متصفح مباشرة. لذلك يتم تحويلها أثناء **مرحلة البناء فقط** إلى ONNX باستخدام Optimum. بعد نشر الموقع، يقرأ المتصفح ملفات ONNX المحلية الموجودة داخل `/models/`، ولا يعتمد محرك الترجمة على API سحابي.

وثائق Transformers.js تسمح بتعطيل النماذج البعيدة (`env.allowRemoteModels = false`) وتحديد مسار نماذج محلي. كما تدعم التخزين المخبئي للملفات وWASM. لذلك هذه النسخة تمنع التحميل البعيد أثناء الترجمة وتستخدم النماذج الموجودة في الموقع. 

## أسهل طريقة بدون كمبيوتر

1. أنشئ مستودع GitHub عام جديد من الهاتف.
2. ارفع محتويات هذا المشروع كما هي، مع مجلد `.github/workflows/`.
3. تأكد أن الفرع اسمه `main`.
4. من `Settings → Pages` اختر النشر عبر GitHub Actions.
5. شغّل workflow: **Build and deploy Offline translator**.
6. بعد نجاحه افتح رابط GitHub Pages على الهاتف.
7. افتح الاتجاه العربي→الفرنسي واضغط ترجمة مرة واحدة ليتم تجهيز النموذج المحلي.
8. كرر ذلك للفرنسي→العربي.
9. بعد اكتمال تجهيز النموذجين، افصل الإنترنت واختبر الترجمة.
10. من Chrome اختر **إضافة إلى الشاشة الرئيسية / تثبيت التطبيق** إن ظهر الخيار.

## مهم

النسخة النهائية تحتاج إلى حجم كبير لأن الأوزان الأصلية لكل نموذج تدور حول 300MB قبل التحويل. لم يتم تضمين الأوزان داخل ملف ZIP، لأن GitHub لا يناسب رفع ملفات نموذج بهذا الحجم إلى مستودع Git عادي. الـworkflow ينزّلها ويحوّلها عند البناء ثم يضعها داخل حزمة الموقع المنشورة.

## الخصوصية

- لا يوجد `INTERNET` permission لأن هذا موقع ويب وليس APK.
- الترجمة نفسها تتم داخل المتصفح.
- لا يوجد حساب.
- لا توجد إعلانات.
- لا توجد Analytics.
- لا يوجد إرسال للنص إلى API.
- لا يتم حفظ نصوص المستخدم تلقائيًا في التطبيق.

## اختبار Offline

بعد تحميل النموذجين مرة واحدة:

- أغلق Wi-Fi وبيانات الهاتف.
- افتح الموقع المثبت من الشاشة الرئيسية أو افتح الصفحة المخزنة.
- أدخل جملة جديدة.
- اضغط ترجمة.

إذا نجحت الترجمة مع الإنترنت مقطوعًا، فهذا هو الاختبار العملي الذي يثبت أن مسار الترجمة المحلي يعمل.
